Sub-Query
=================
A sub query is query inside another query.
it is written inside parenthesis() and it result is used by the outer query
 
it is also called as 
inner query
nested query
inner select.



General Syntax
====================
Select column_list
from table
where coloumn OPEARTOR(select column from table where condition);


purpose of subquery
==========================
To breakdown complex problems into smaller queries 
to use the result of one query as input to another query.
to avoid multiple steps.

Types of subqueries
=========================
1.single row subquerie
2.multi-row subquerie
3.corelated subquery
4.exists/not exists sub query


1.Single row subquery
==========================
Single row subquery returns exactly when one row and one column.they use comparision operators like =,<,<=>,>=,!=

Characterstics
==========================
returns only one value
can use single-value comparisions operators
if subquery returns no rows or multiple rows it causes an error.


Syntax
======================
select columns
from table
where column operator(select column from table where condition);


2.Multi-row subquery
=========================
(a).Multi-row subqueries with in 
----------------------------------
a multi row subquery returns more than one row,the in operator is used when you want to compare a value with multiple values
returned by the subquery.

characterstics
------------------------
returns  multiple rows,
any and some are interchange
condition  is true if any of the values satisfy the condition.
often used with IN,>ANY,>=ANY,<=ANY


SYNTAX
--------------------
select coulumns from table 
where column operator any/some(select column from table where condition ).

(B).Multi row subqueries (all).
------------------------------------------
The all operator means the condition must be true for all values returned by the subquery

Characteristics
============
* Returns multiple rows
* ANY or SOME are interchange
* Condition is true if ANY of values satisfies the Condition
* Often used with IN, > ANY , < ANY , > = ANY , < = ANY

Syntax
======
select columns from table
	where column operator ANY / SOME(select column from table where condition);

b).Multi-row Subqueries (ALL)
=======================
The All operators means the condition must be true for all values returned by the subquery.

Characteristics
============
* Condition must be true for all values in the subquery result
* Often used with > ALL , < ALL, > = ALL, < = ALL
* > ALL means greater than maximum value
* < ALL means less the minimum value

Syntax
======
select column from table
	where column operator ALL(select column from table where condition);

3.Nested Subquery
==============
Nested subqueries are subqueries within subqueries , they can be multiple levels and deep are executed from the innermost to the outermost.

Characteristics
============
* Multiple levels of nesting
* Inner queries execute first
* Can combine different types of subqueries
* Useful for complex condition

Syntax
=======
select column - list from table
	where Column  = (select column from table where column = (select column from table where condition));

4.Correlated Subquery
==================
Correlated Subqueries are subqueries that reference column from the outer query, unlike regular subqueries that execute once, correlated subqueries execute once for each row proceed by the outer query.

Characteristics
============
* References column from the outer query
* Execute multiple time(once per outer now)
* Cannot be executed independently
* Often used with EXISTS / NOT EXISTS
* Generally slower than non - correlated subqueries

Syntax
======
select column
	 from table outer - alias
		where condition ( select column 
			from table2 inner - alias
				where inner - alias , column outer - Alias. Column);
 
5.Exists / Not Exists Subquery
======================
Exists used to test whether a subquery returns any rows, it returns TRUE if the subquery returns at least one row, false otherwise.

Characteristics
============
* Returns TRUE / FALSE
* More Efficient then IN for large datasets

Syntax
======
select column from table1
	where EXISTS(select 1 from table2 where condition);

select column from table1
	where NOT EXISTS(select 1 from table2 where condition);
